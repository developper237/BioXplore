Accessibility Statement

BioXplore is committed to making our platform accessible and usable by everyone, regardless of ability or technology.

Last updated: February 2025

Our Accessibility Commitment

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. These guidelines explain how to make web content more accessible to people with disabilities. We regularly audit our platform and actively work to address any gaps we identify.

1. Accessibility Features

BioXplore includes the following built-in accessibility features:

Full Keyboard Navigation

Every interactive element can be reached and activated using only a keyboard.

High Contrast Colours

Text and UI elements meet WCAG AA contrast ratio requirements (4.5:1 minimum).

Alternative Text

All meaningful images include descriptive alt text for screen reader users.

Resizable Text

Text can be resized up to 200% without loss of content or functionality.

Large Click Targets

Buttons and links meet the minimum 44×44 px touch target size recommendation.

Semantic HTML

Pages use proper heading hierarchy, landmark regions, and ARIA labels.

Skip Navigation

A "Skip to main content" link is available at the top of every page.

No Seizure Triggers

We avoid flashing content and rapid animations that could trigger photosensitive seizures.

2. Keyboard Navigation

BioXplore can be navigated entirely without a mouse. Here are the standard keyboard shortcuts that work across the site:

Key / Combination Action
TabMove focus to the next interactive element
Shift + TabMove focus to the previous interactive element
Enter or SpaceActivate a focused button or link
EscClose a modal, dropdown, or overlay
↑ ↓Navigate within dropdown menus or lists
Home / EndJump to start or end of a list
Alt + ←Go back to the previous page (browser)

Focus indicators (the visible outline around a focused element) are intentionally prominent on BioXplore. If you see an outline disappear or become hard to see on any element, please let us know.

4. Screen Reader Support

BioXplore is built with screen readers in mind. Our implementation includes:

  • ARIA landmarks — <header>, <main>, <nav>, <footer> for easy region navigation
  • ARIA labels on icon-only buttons (e.g. close, hamburger menu)
  • Live regions (aria-live) for toast notifications and dynamic status updates
  • Form labels explicitly associated with every input field
  • Table headers properly marked with <th scope> for data tables
  • Link purpose — link text is descriptive and meaningful out of context

5. Conformance Status

BioXplore partially conforms to WCAG 2.1 Level AA. Here is our current status by principle:

WCAG Principle Status Notes
Perceivable — Information is presentable to all users ✓ Pass Alt text, captions, colour contrast all meet AA
Operable — UI components are keyboard accessible ✓ Pass Full keyboard navigation, no keyboard traps
Understandable — Content is readable and predictable ~ Partial Error suggestions on forms in progress
Robust — Compatible with assistive technologies ↗ In Progress ARIA implementation ongoing for dynamic content

6. Known Limitations

We are aware of the following areas that need improvement and are actively working on them:

  • Product image carousels — some auto-playing elements may not announce state changes to screen readers. Fix planned for Q2 2025.
  • Checkout WhatsApp flow — the handoff to an external app may break screen reader flow. We are investigating an in-app alternative.
  • PDF content — our Conservation Policy PDF may not be fully accessible. A structured HTML version is in development.
  • Complex data tables — on mobile, some table layouts reflow in a way that may lose column context. We are working on responsive table patterns.

If you encounter an issue not listed here, please tell us about it.

7. Assistive Technology Compatibility

BioXplore has been tested with the following combinations of assistive technologies and browsers:

  • NVDA + Chrome (Windows) — primary testing environment
  • JAWS + Chrome / Edge (Windows)
  • VoiceOver + Safari (macOS and iOS)
  • TalkBack + Chrome (Android)

We recommend using an up-to-date version of your preferred browser and assistive technology for the best experience.

If BioXplore does not work well with your particular assistive technology setup, please contact us and we will do our best to accommodate your needs or provide content in an alternative format.

8. Feedback & Contact

Accessibility is an ongoing effort, not a one-time checklist. We welcome all feedback. If you experience any barriers, find something that doesn't work as expected, or would like content in an alternative format, please reach out:

  • Email: accessibility@bioxplore.com
  • Response time: We aim to respond within 2 business days
  • Alternative formats: Content is available in large print or plain text on request

If you are not satisfied with our response, you have the right to escalate your complaint to the relevant national disability authority or digital accessibility body in your country.
